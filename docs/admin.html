Set up the admin login

The admin login unlocks a GitHub key that is allowed to change requests and files in the repository. This form encrypts that key with your password and saves it to the site. Your password is not saved anywhere, so it can't be recovered: if you forget it, set up the login again with a new key.

  1. Create a GitHub key for the website: new fine-grained token. Name it rig website admin; Resource owner adamslab-gibert, Only select repositories → metamaterial-rig, and Repository permissions: Contents and Issues → Read and write. Generate it and copy it.
  2. Paste it below, choose the admin password and click Save admin login. Paste the key only here, nowhere else.

These reach the rig computer within about 30 seconds (Start rig.bat must be running there). Connect & home connects both Enders and the Mark-10 on the ports used last time, loads the corner coordinates and homes. Make sure nobody is working at the rig before moving it from here.

Halt now: the rig stops where it is, with the tool lifted clear, and the test is marked failed. Use maintenance mode to free the rig if needed, then Home now. The next pattern is built from scratch.

Emergency stop: both Enders stop at once, mid-move. To restart, you need to power-cycle the Enders (switch them off and on), then Connect & home. In a real emergency, switch off the power at the rig: these buttons take 20–30 s to arrive.
