The Data Set

This is every pattern tested on this rig, each with its measured force–displacement curve. The curve shows how much force it took to compress the structure as it was squeezed. The data set grows with every new test, both from the queue and from automatic testing. It is free to use for research, teaching or your own models under the CC BY 4.0 licence. How the Island Algorithm Works

Most patterns in the data set were made by the island algorithm. It grows several separate groups of inserts, called islands, so that every empty cell ends up between at least two islands. Cells count as neighbours when they share an edge or a corner. Patterns submitted to the queue are checked against the same rule and counted in the matching group above.
