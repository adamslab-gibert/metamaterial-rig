How a request runs

  1. You submit. One pattern from the editor, or a zip of up to 100. It opens as a request on GitHub.
  2. It is checked. A bot checks the patterns and adds the request to the queue, or explains what to fix.
  3. The rig picks it up. When the machine is online and idle, it takes the oldest request.
  4. The robot builds and tests each pattern. It places the inserts, compresses the specimen to 20 N and photographs it.
  5. Results are posted. Curves and photos appear on your request, and the runs are added to the data set.

Run by Adams Lab. Source and results: GitHub repository. Measured data are published under CC BY 4.0.
