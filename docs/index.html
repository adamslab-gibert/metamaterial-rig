Programmable Metamaterial Test Rig

Meet Sir Squish-a-Lot: a metamaterial that gets its properties from its structure rather than from the material alone. This green knight is made of soft silicone rubber with 105 diamond-shaped unit cells. Any unit cell can receive a rigid insert, which stiffens it locally and so changes how the whole structure responds, and different insert patterns produce different responses. Try it yourself: design a pattern, and the rig places the inserts, compresses the structure and measures how it deforms. You can watch it happen live.

How a request runs

  1. You submit. One pattern from the editor, or a zip of up to 100. It opens as a request on GitHub.
  2. It is checked. A bot checks the patterns and adds the request to the queue, or explains what to fix.
  3. The rig picks it up. When the machine is online and idle, it takes the oldest request.
  4. The robot builds and tests each pattern. It places the inserts, compresses the specimen to 20 N and photographs it.
  5. Results are posted. Curves and photos appear on your request, and the runs are added to the data set.
