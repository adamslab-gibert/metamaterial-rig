Option 2

Upload a batch of patterns

What to upload

One .zip file with two text files inside, for up to 100 patterns:

patterns (or patterns.txt)
One pattern per line: 105 digits of 0 and 1, bottom row first, left to right, 1 = insert.
index (or index.txt)
One number per line: 0 for the first pattern, 1 for the second, and so on. Same number of lines as patterns.

Example: the first lines of each file

patterns

111110111101111011110110101100011010111110…
