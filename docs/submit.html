Option 2

Upload a batch of patterns

What to upload

One .zip file with a text file called patterns (or patterns.txt) inside, for up to 100 patterns. The file holds one pattern per line: 105 digits of 0 and 1, bottom row first, left to right, 1 = insert. The patterns are tested in the order they are listed.

Example: the first lines of the file

patterns
111111111111111111111100111100111110111110…
111110111101111011110110101100011010111110…
