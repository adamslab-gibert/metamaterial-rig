# Results

Written automatically by the lab agent (`lab/agent.py`); do not edit by hand. Published under CC BY 4.0.

- `<request>/` — one folder per tested request (a batch: `<request>/<index>/` per pattern, plus `<request>/batch.json`):
  `curve.json` (200-point curve and metadata), `raw.csv` (every reading), `pattern.txt`, `curve.png`,
  `frames/` + `frames.json` (photos during compression with the displacement and force at each).
- `index.csv` — one line per test.
- `dataset_additions.csv` — each successful test in data-set form; the website adds these to the data set.
- `leaderboard.json` — scored challenge entries.

See section 6 of the main README for the details.
