# Programmable Metamaterial Test Rig

The public website of the ADAMS (Advanced Dynamics and MechanicS Lab) test rig at Purdue University:
**https://adamslab-gibert.github.io/metamaterial-rig/**

A soft silicone metamaterial with 105 diamond-shaped cells. Any cell can receive a rigid insert, and the
pattern of inserts sets how the whole structure responds. On the website you can design a pattern, send it
to the rig, watch the robot build and compress it live, download the measured curve, explore the full data
set and enter the inverse design challenge.

**What is here**

- `docs/` – the website and the published data set (`docs/data/`).
- `results/` – every test run from the website, one folder per request, plus `dataset_additions.csv`.
- `lab/`, `control/`, `.github/` – the software that links the rig to this repository.
